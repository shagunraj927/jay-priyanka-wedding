JAY & PRIYANKA – WEDDING INVITATION WEBSITE
===========================================

This folder holds the complete website as one file: index.html.
All photos, fonts, the scratch card, the countdown and the piano music are already inside it.

-------------------------------------------------
PUT IT ONLINE FOR FREE (about 2 minutes)
-------------------------------------------------
1. Unzip this file.
2. Go to  https://app.netlify.com/drop
3. Drag the unzipped folder onto the page.
4. You will get a public link, for example
   https://jay-weds-priyanka.netlify.app
   (Sign up for a free account to keep the site and choose this name under
   Site configuration -> Change site name.)
Anyone can open the link on any phone. No login is needed.

Other free options that work the same way: Vercel (vercel.com) or GitHub Pages.

-------------------------------------------------
USE YOUR OWN NAME, e.g.  jayandpriyanka.com
-------------------------------------------------
1. Buy the name from GoDaddy, Hostinger or Namecheap (about Rs 200-1,000 a year).
2. In Netlify: Domain management -> Add a domain -> type your name.
3. Netlify shows you DNS records. Add them at the place where you bought the name
   (or switch to Netlify's name servers when it offers that).
4. Within a few hours the invitation opens at your name, with free HTTPS.

-------------------------------------------------
CHANGING DETAILS LATER
-------------------------------------------------
Open index.html in any text editor (Notepad, TextEdit, VS Code) and search for:

  VENUE CONFIGURATION   -> venue names and Google Maps links
  WEDDING_AT            -> the date and time the countdown counts to
  Saturday, 5 December  -> the date lines shown on each function page

Save the file and drag the folder onto Netlify again to update the site.
